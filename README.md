# dsh-bongo-fish · 邦戈鱼打字挂件

<img src="icon.png" width="88" align="right" alt="邦戈鱼">

一个 BangoCat 风格输入反馈小挂件，可以自动吸附在 DSH 输入框及窗口边缘，支持自定义形象和音效。

![dsh-bongo-fish 邦戈鱼键盘反馈](preview.png)

## 安装

在 DSH 桌面端「插件 → 添加插件」中输入：

```text
dsh-bongo-fish
```

安装或更新后重启 DSH。若客户端提示同名插件已安装，请先卸载旧版再安装新版。

## 功能

- **按键反馈**：支持中文输入法和标点；长按保持按下，系统连发不重复播放音效。监听范围为 DSH 页面，不是跨应用的系统级键盘监听。
- **正常手**：瞬间切换上手／下手图片并下沉，无缓动；下沉深度可调至 180%。
- **萌圆手**：按下下压、压扁，松开弹性回位，深度与速度可调。
- **两套独立配置**：正常手和萌圆手分别保存手部大小、比例、位置、镜像、出手顺序和动作参数。切换样式自动载入对应配置，修改互不影响。
- **拖动磁吸**：支持输入框上沿、下沿与窗口边缘吸附。
- **提醒拍手**：弹出选项卡、请求工具权限、一轮结束时自动拍手；「提醒时拍手次数」可调 0～9，默认 3，0 为关闭。

## 菜单与素材

右键挂件或点击悬浮的 ☰ 打开菜单，设置实时生效并保存在当前浏览器。

「自定义素材」页支持：

- **左右箭头切换样式**：下手可选默认／样式二，音效可选默认／水滴声；选中后固定使用，不自动混播。只有一个样式时箭头置灰。
- **上传图片**：本体、正常手上手／下手、萌圆手分别替换，左右手共用一份素材；推荐透明 PNG，单张不超过 10MB。
- **上传音效**：选择本机音频、试听、恢复默认，单个不超过 10MB；可用格式以浏览器解码能力为准。

自定义素材保存在当前浏览器中，不上传。切换内置图片保留已上传图片；「恢复默认音效」会清除上传的音效。不同浏览器或访问地址之间不自动同步。

### 手部默认布局

| 设置 | 正常手 | 萌圆手 |
|---|---:|---:|
| 手部大小 | 25% | 18.6% |
| 手部高宽比 | 76% | 73% |
| 两手间距 | 53.3% | 44.6% |
| 双手中心水平位置 | 41.6% | 39.9% |
| 手部垂直位置 | 82.2% | 90.7% |

首次迁移到独立配置时，手部布局按上表初始化；音量和吸附位置等公共偏好保留。单项复位使用当前样式的默认值。

## 水滴高低律动

在「声音与提醒」页开启「律动音效 → 水滴高低律动」（默认关闭）：

- 固定 24 步高低乐句，音域为原音至高一个八度，轻重按 8 步循环。
- 每次按键立即播放一声，不自行连播；停顿超过一秒，从乐句开头重新开始。
- 快速输入时缩短尾音，响度按默认固定音效对齐，不叠加随机音高。
- 开启时优先使用律动音效；关闭后恢复素材页选择的声音，自定义音效仍保留。提醒拍手也使用当前音效模式。
